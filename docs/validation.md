## 此次公开源码发布

此次发布包含便携模板、兼容源码、固定输入校验、构建逻辑和离线测试。构建输入路径已经参数化，第三方运行时、办公 skills 和原始测试环境未随仓库发布。**没有从此次公开源码完整重建并重新运行同一套 Win7 成品验收**，因此历史验收不能直接证明读者新建输出的结果。

CI 使用现代 Windows 和 Node 24，只验证源码语法、便携模板、桥接与清单逻辑，以及安装依赖后兼容层的行为。CI 没有 Win7 虚拟机，没有真实 API Key，也不发布可运行压缩包。

以下项目仍需各自验收：其他 Win7 版本和补丁组合、独立标准账户、学校设备策略、真实云端 API 的 TLS/代理/网络、图片附件、持久交互终端。Python 模块能够导入不代表所有办公任务或文件格式都已验证；七项进程测试也不构成完整安全审计。
